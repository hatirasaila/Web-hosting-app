Saila's Hosting - Landing Page

Landing page for a web hosting company, built with React.js

This is a modern, responsive, and visually appealing landing page for a web hosting company, created using React.js. The page is designed to attract potential customers with clear information about services, pricing, features, and support.

Features

React.js Front-End: Built entirely with React for fast rendering and a smooth user experience.
Responsive Design: Works perfectly on desktop, tablet, and mobile devices.
Interactive Navbar: Smooth scrolling to sections like Pricing, Features, Support, and About Us.
Login & Sign Up Modals: Modern forms integrated for user authentication.
Theme Toggle: Users can switch between light and dark mode easily.
Modern UI/UX: Attractive layout using Tailwind CSS, custom fonts (Inter), and subtle animations.
SEO & Metadata: Optimized meta tags for social sharing and search engines.

Sections

Hero Section: Highlights company branding, key value proposition, and call-to-action.
Pricing: Showcases pricing plans with clear benefits.
Features: Lists key hosting features like SSD storage, SSL, uptime guarantee, and 24/7 support.
Support: Provides guidance and contact options for customers.
About Us: Company overview with mission and values.

Technologies Used

React.js - Front-end library for building interactive UI
Tailwind CSS - For modern styling and responsiveness
JavaScript / TypeScript - Core scripting
Vite - Fast React development environment
Google Fonts (Inter & JetBrains Mono) - Professional typography
